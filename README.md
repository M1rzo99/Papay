## ✨ What is PAPAY?
PAPAY is a restaurant aggregator where users can **discover restaurants**, browse menus & prices, leave reviews, and **chat in real-time**. Built as a full-stack learning project covering REST APIs, authentication, and WebSockets.

## 🚀 Features
- 🏪 **Restaurant Management** — Add & browse restaurants with menus and prices
- ⭐ **Reviews & Ratings** — Users share feedback on visited restaurants  
- 💬 **Real-time Chat** — Socket.io powered messaging
- 🔐 **JWT Auth** — Token-based auth with secure cookie management

## ⚡ Quick Start
```bash
git clone https://github.com/M1rzo99/papay-backend.git
cd papay-backend
npm install
cp .env.example .env
npm start
```

## 🔑 Environment Variables
```env
PORT=3000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
COOKIE_SECRET=your_cookie_key
```
